# Hearthly

Marketplace for neat, fairly used household items.

- **Buyers** browse the public floor, filter listings, and message sellers.
- **Sellers** create accounts in `/seller/register`, then post and manage items from `/seller/dashboard`.

This demo stores accounts, listings and inquiries in the browser (`localStorage`) so it works without a database. Demo login: `ada@hearthly.demo` / `demo1234`.

```bash
npm install
npm run dev
```
